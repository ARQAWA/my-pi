# Упрощение плана

Этот навык для агентов проекта и планирования. Запускай его, когда сумма задач плана больше 10 SP. Шкала лежит в `PROCESS.md`, в блоке под правилом 3.

1. Ищи решение проще, но только внутри заказанного. Заказанное это цитаты владельца в задании.
2. Никогда не выбрасывай явно заказанное требование из цитат.
3. Хочешь срезать что-то сверх этого? Не режь сам. Пометь это «крит: сверх заказа» для владельца и объясни причину.
4. Появилась задача от 3 SP? Выполни навык [decompose](../decompose/SKILL.md) снова.
5. Проверь результат, с повторной decompose, если она была: свежий `bossy` по навыку `reviewer` (`agent_type`, `role_file`, `include: ["user_messages"]`). Повторяй со свежим проверяющим до `CLEAN`.
6. Верни список задач с SP, цитатами и суммой. Сумма всё ещё больше 10? Скажи об этом прямо и не повторяй круг.
