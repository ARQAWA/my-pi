# Планирование

Этот навык для агентов проекта и планирования. Он часть процесса разработки, не продукта. Шкала SP лежит в `PROCESS.md`, в блоке под правилом 3. Используй только значения 0, 1, 2, 3, 5, 8, 13.

1. Выпиши цитаты владельца из задания дословно. План держит всё заказанное и ничего сверх.
2. Оцени всю историю целиком. Суди по трём признакам: объём работы, сложность, неопределённость. Это первая оценка.
3. Раздели историю на задачи. У каждой задачи: название, SP, неизвестные и цитаты владельца, которым она служит.
4. Проверь план: свежий `spotty` по навыку `reviewer` (`agent_type`, `role_file`, `include: ["user_messages"]`). Повторяй со свежим проверяющим до `CLEAN`. Исправляй находки одним набором.
5. Есть задача от 3 SP? Выполни навык [decompose](../decompose/SKILL.md).
6. Сумма задач больше 10? Выполни навык [simplify](../simplify/SKILL.md).
7. Верни короткий список: первую оценку, итоговые задачи с SP и цитатами, сумму.

Навыки идут по порядку: plan, decompose, simplify. Запускай их сам, без вопросов к Main. Последняя проверка: `bossy` после simplify. Не было simplify? Последняя проверка `spotty` после последнего этапа.
