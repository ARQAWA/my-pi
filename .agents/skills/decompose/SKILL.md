# Декомпозиция

Этот навык для агентов проекта и планирования. Запускай его, когда в плане есть задача от 3 SP. Шкала лежит в `PROCESS.md`, в блоке под правилом 3.

1. Для каждой такой задачи найди неизвестные. Убери их: прочти код или сделай замер. Не гадай.
2. Перепланируй задачу на подзадачи. Оцени каждую по шкале: объём работы, сложность, неопределённость. У каждой подзадачи те же цитаты владельца, которым она служит.
3. Осталась подзадача от 3 SP? Повтори шаги 1 и 2 для неё. Повторяй, пока каждая задача плана не станет 0, 1 или 2.
4. Не добавляй ничего сверх заказанного.
5. Проверь результат: свежий `spotty` по навыку `reviewer` (`agent_type`, `role_file`, `include: ["user_messages"]`). Повторяй со свежим проверяющим до `CLEAN`.
6. Верни обновлённый список задач с SP, цитатами и новой суммой.
