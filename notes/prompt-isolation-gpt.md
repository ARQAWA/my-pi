# GPT evidence: prompt/tools isolation

Decision: accept required module independence through Pi's native prompt sections, with a measured behavioral tradeoff. Do not describe the change as neutral. Owner: «Когда мы делаем эти отдельные модули, они должны быть полностью изолированы, самодостаточны, чтобы мы могли включать и выключать, как feature флаги.» The implementation and exact instruction move are in `extensions/RQW-tools/index.ts`, `extensions/RQW-prompt/SYSTEM.md` and `notes/prompt-tools-isolation.md`; package coverage is `test/prompt-tools-isolation.test.ts`. The code review was CLEAN; the previously completed suite reported 400 pass, one skip, plus Bun coverage. No new live tests were run for this documentation update.

`notes/prompt-isolation-gpt.csv` is the unmodified 72-row results table. Frozen comparison: base `0473ab62aa81acb3b172451a876f40e2bd94248a`, variant `04aa50fce13f05f3a0d286b504fcac521ec992ca`. Two models, three question tasks (T01/T03/T06) and three edit tasks (EDIT/WRITE/MULTI), three repetitions per model/task/snapshot. Questions used three GPT-6.1-sol low judge votes per checklist item, combined by majority. The judge used no tools. Edit acceptance was independently checked. The runs used RQW-settings, RQW-prompt, RQW-tools and RQW-context, not RQW-agent/review. All 72 processes exited successfully; all 36 edit acceptance checks passed. Recovered tool errors: base 10, variant 8, so the runs were not error-free.

| Question model | Base wall / steps / checklist | Variant wall / steps / checklist | Variant minus base |
|---|---|---|---|
| GPT-6.1-sol medium | 36.94 s / 4.56 / 87.78% | 38.79 s / 5.11 / 84.44% | +1.85 s / +0.56 steps / -3.33 points |
| GPT-6-sol low | 21.66 s / 4.33 / 74.44% | 21.07 s / 4.00 / 81.11% | -0.59 s / -0.33 steps / +6.67 points |

Each question cell contains nine runs. On medium the paired 90% bootstrap intervals, conditional on these tasks, are [-0.92, +4.66] s, [+0.22, +0.89] steps and [-5.56, -1.11] checklist points. Four lost medium checklist items are missing references to Rust field declarations in `rust/services/auth/src/config.rs`; the answers still name the correct keys and values 600/400. On T06 the variant includes the 30 s auth blocker delay in all three medium repeats, which the base misses. This is a measured cost in steps and citation completeness, not proof of a general loss of factual correctness. The original benchmark's REJECT means *not behaviorally neutral*, not that the required independence should be left broken.

Pi 1.3.0 appends custom sections after cwd even with `customPrompt`; guidelines apply only to the stock prefix. Moving the search instruction changes position; two redundant partial-write reminders disappear, while the complete rule remains in `extensions/RQW-tools/descriptions/write.md`. No byte-for-byte prompt identity or general quality equivalence is claimed. Keeping the original positions needs additional interpolation or coupling to another extension's text and is not adopted. Long writes over 400 lines, Windows/Linux, long contexts and a full agent/review lifecycle were not measured here. Four optional `SYSTEM.md` manifesto edits are separate and remain unadopted; see `notes/bench46-gpt.md` and `notes/bench46-gpt.csv`.
