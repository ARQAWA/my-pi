Run a code_writer: a cheap worker session that writes code and configs (source, tests, SQL, JSON, schemas, scripts, build and CI files), never documentation or prompts, and may run a focused check of its own change. Use it for noisy mechanical work that burns tokens; do not use it when the brief would be longer than making the change yourself. One assignment per call; every call starts with a fresh context, so the brief must be complete. Trust the result and do not redo the work. Independent calls may run in parallel, but never two code_writers on the same file. Its result arrives later as a message [code_writer#N] ...; do not wait or poll. Parameter: task, the brief, with these fields: goal; files (exact paths); the exact decided change; constraints; how to check (the command). The worker makes no decisions and changes no git state; an ambiguous brief comes back as blocked. Returns code_writer#N at once.
