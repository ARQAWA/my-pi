# Список дел

Используй `todo` для работы из нескольких частей. Пиши пункты понятными русскими словами. Для больших пунктов добавляй подшаги.

Обновляй список вместе с работой, не отдельными ходами. Передавай несколько новых или изменённых пунктов одним вызовом. Завершай последний пункт вместе с последней проверкой.

Если ждёшь владельца или внешнее событие, отметь пункт `blocked` и укажи причину в `note`. Когда список закрыт, начинай новую работу с `new: true`. По просьбе выключить список вызови `todo` с `off: true`.
