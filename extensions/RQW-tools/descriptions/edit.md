Replace exact text in files. Give path and edits: [{oldText, newText}, ...] for one file, or put a path on each edits[] entry to change several files in one call; the top-level path is the default for entries without their own. All edits of one file are matched against the original file, not one after another: each oldText must be unique in that file and must not overlap another edit of it; add surrounding lines to make it unique. Each file changes all-or-nothing: if any of its edits fails, that file stays untouched and the other files are still edited. Read a file before editing it. The result has one line per file; when text is not found, it shows the nearest matching lines with line numbers.
