Create or overwrite files; missing parent directories are created. Give path and content for one file, or files: [{path, content}, ...] for several files, never both in one call and never one file twice. Use write for new files and full rewrites; change part of a file with edit. A response has an output limit: write a file over about 400 lines in parts, each part in its own response: the first with write, then each next with edit whose oldText is the unique last lines of the file and whose newText is those lines plus the next part. The result has one line per file.
