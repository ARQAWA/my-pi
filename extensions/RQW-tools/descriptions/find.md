Find files and directories by glob pattern; directories end with "/". Returns paths relative to the search directory, unsorted. Respects .gitignore; hidden files are included.
- A pattern without "/" matches file and directory names at any depth, e.g. "*.ts"; "app" returns directories and files named app, not what is inside them. A pattern with "/" matches the end of the full path at any depth, e.g. "src/**/*.spec.ts"; "app/**" returns everything under every directory named app. Braces list alternatives in one pattern, e.g. "{app/**,*.toml,*compose*,Dockerfile*}".
- Paths in .gitignore are skipped, inside a git repository and outside it, so an empty answer does not prove a file is absent. grep outside a git repository still searches them. When ignored paths also match, the answer ends with a note such as "Also 1757 entries in ignored paths: node_modules/ 1757"; set path to a directory it names to list it. find cannot list paths the note names one by one.
- No result count cap by default; output is cut at 50KB. If cut, narrow the pattern or path.
- Use find for file names and grep for file contents.
- Several searches in one response run in parallel. Run every search that may be useful in one response.
