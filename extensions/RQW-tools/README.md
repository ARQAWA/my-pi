# RQW-tools

Base tools, ordered execution and background jobs.

Modules and resources live beside `index.ts`; subfolders group needed resources.

## Unchanged reads

The unchanged-read cache compares the file's mtime and content hash from before
stock read with its version after the asynchronous image check. A changed version
is not remembered, so a later read returns the new content rather than the note.
The full contract is `D-TOOLS-UNCHANGED-READ` in `DECISIONS.md`.

## Background activity counts

The main registry offers a version-1 source on `rqw:running-counts:offer` at each
`session_start`, and answers `rqw:running-counts:request` with `{ version: 1, reply(source) }`.
Its `snapshot()` returns `{ agents: 0, backgroundProcesses: number }`. This counts
handed-off jobs that are still running or queued, including file-tool jobs. Foreground
calls and completed undelivered results do not count. Wait registrations refer to the
same jobs and never add another count.

`subscribe(listener)` reports changed counts and returns an unsubscribe function.
Replacing or stopping the source sends `null` and clears its subscriptions. An ended
source has a zero snapshot and immediately sends `null` to new subscribers. Consumer
exceptions do not affect jobs. Shutdown stops the producer. Child `createTools`
registries do not publish process counts; their activity belongs to the subagent.
