# Native web declaration provenance

`web-native-tools.json` contains the full reserved `web.run` declaration from OpenAI Codex, Copyright 2025 OpenAI, Apache License 2.0. It is generated from official `rust-v0.164.0`, commit `6aaac694803004a63c6f393d153c96d22521a6b9`. The source files and their SHA-256 hashes are recorded in `test/fixtures/web-schema-provenance.json`. The complete license is included in `LICENSE-CODEX`.

The schema comes from `codex-rs/codex-api/src/search.rs` and `codex-rs/ext/web-search/src/schema.rs`, generated with schemars 0.8.22, serde 1.0.228 and serde_json 1.0.149. The official draft-2019-09 settings inline subschemas and omit nullable Option types. The schema then passes through `codex-rs/tools/src/json_schema.rs` without compaction and the `JsonSchema` representation in `codex-rs/tools/src/json_schema/types.rs`. That representation intentionally drops `format` and `minimum`, retains field descriptions and sorted required names, and does not add `additionalProperties: false`.

The namespace shape and function description come from `codex-rs/ext/web-search/src/tool.rs`, `codex-rs/tools/src/responses_api.rs` and verbatim `codex-rs/ext/web-search/web_run_description.md`. The declaration inputs are byte-identical in official `rust-v0.163.0`, commit `83086188ae0614bd882818ff1aa23f3194962012`, apart from allocation-only changes in the wire representation, from `String` and `Vec` to boxed storage; serialization is unchanged.

No generated declaration snapshot was found in either official source tree. A standalone Rust generator extracts the original SearchCommands types and upstream generator, sanitizer and wire representation; it builds no Codex application or transport. Regeneration must use that complete source pipeline, not a handwritten subset or direct schemars output. The fixture pins the resulting declaration and description hashes.

The backend reserves this exact declaration. Publishing all native fields is protocol compatibility, not CLI capability: `web-commands.ts` still permits only text `search_query`, `open`, `click` and `find`. Other declared commands are explicitly unavailable and are rejected before a search request. The full description and schema are unmodified; CLI-specific constraints stay in the developer instructions instead.
