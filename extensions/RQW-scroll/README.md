# RQW-scroll

In fullscreen, the first Escape returns a scrolled transcript to the latest message, whether the turn or background work is running or idle. It does not interrupt or arm double Escape. At the bottom Escape keeps turn control (interrupt; double press stops the background, see RQW-send-now). Dialogs, autocomplete and transcript search keep their own Escape.

Modules and resources live beside `index.ts`; subfolders group needed resources.
